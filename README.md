# E-Sports Team Manager - CS104 Mini Project

## วิธีรัน
```bash
pip install -r requirements.txt
python app.py
```
เปิดเว็บที่ http://127.0.0.1:5000

## โครงสร้างฐานข้อมูล
มี 5 ตารางหลัก: teams, players, gear, tournaments, matches พร้อม PK/FK และ Mock Data มากกว่า 10 records/ตาราง

## การส่ง
นำขึ้น GitHub เป็น `githubusername/CS104_ชื่อกลุ่ม` และ Deploy บน PythonAnywhere/Render ตามใบงาน
